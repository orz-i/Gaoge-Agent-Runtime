# Security policy

## Supported versions

Only the latest `v0.1.0-beta.*` release receives security fixes during the
initial Beta.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Include the
affected package and version, reproduction steps, impact, and any known
mitigation. Do not open a public issue before a fix or coordinated disclosure
is available.

Maintainers will acknowledge a complete report within five business days and
will provide a status update at least every ten business days while it remains
open.

Never include production credentials, tokens, prompts, model outputs, or user
data in a report. Replace them with minimal synthetic fixtures.

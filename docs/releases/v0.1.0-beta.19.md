# Agent Runtime 0.1.0-beta.19

Large histories can now compact into several ordered, lossless transcript
artifacts. Each artifact remains within the existing 4 MiB durable ceiling;
concatenating their JSON message arrays reconstructs the complete removed
transcript. The checkpoint records every part and its content hash. Retained
entries preserve source and turn identities, including host attachment replay.
An individual message exceeding the artifact ceiling still requires a host blob
contract and fails with the existing typed size error rather than truncating data.

This is a Go prerelease API change: `PortableCompaction.Artifact` is replaced by
`PortableCompaction.Artifacts`. Hosts must persist all parts before committing
the rollover through the existing Context Store contract. No SQL migration or
HTTP response shape change is required.

`Policy.PreserveRecentTurns` is the preferred inline tail for ordinary compaction
and still defaults to eight. The new frozen `MinimumRecentTurns` defaults to one,
protecting the complete current user turn. Under hard input pressure a host may
retry portable compaction with the preferred tail reduced to that minimum. An
explicit larger minimum remains authoritative. Hosts must reassess the candidate
against the routed model window before sampling; irreducibly oversized required
input still fails closed. This does not retry a failed model generation or change
execution call budgets.

`harness.read_context_artifact` accepts optional `query` for a literal lookup of
at most 256 Unicode characters. Search starts at the Unicode `offset`, returns
`found` and a bounded excerpt beginning at the match, and supports continuation
with `nextOffset`. Results also include `totalRunes`. A missing match applies only
to the requested artifact. Existing paginated reads remain available.

When an artifact ID is mistyped, the correctable Tool result includes bounded
exact references from the caller's durable Turn checkpoint. IDs are not guessed
or remapped. Caller ownership, scope isolation and checkpoint integrity are still
enforced; storage and lineage failures remain fatal.

Upgrade all nine Go modules and the TypeScript client together to
`v0.1.0-beta.19`. The TypeScript archive is
`orz-i-agent-runtime-client-0.1.0-beta.19.tgz` on this GitHub prerelease; npm
publication remains disabled.

## v0.1.0-beta.7 Release Notes

### ✨ Feature

- Host integrations can route Harness cancellation through feature-specific cleanup, including cancellation of remote A2A tasks.

### ⚡ Optimization

- Pending delegations reuse one child task and the prepared task input across polling and runner restarts, without repeating delegation policy checks or charging completed Tool-call budget.

### 🐛 Fixed

- Asynchronous child tasks no longer cause conflicting lifecycle records or let the parent finish before their result is available.
- Cancelling a parent records the child's actual terminal outcome, preserving results that have already arrived.
- Remote cancellation uses the original target configuration and validates the requested revision. Transport failures and nonterminal acknowledgements remain retryable instead of being reported as completed cancellation.

### Upgrade notes

- Upgrade the Go modules together to `v0.1.0-beta.7`. The TypeScript archive is attached to this GitHub prerelease; Beta versions are not published to npm.
- Connect the A2A plugin to Harness and HTTP cancellation routing, and provide the Scheduler as the continuation Worker's `Projector` for automatic wakeup processing.
- Retry an unsuccessful or still-pending remote cancellation with another cancellation request. No HTTP v1 or database schema migration is required.

## v0.1.0-beta.7 中文版本

### ✨ Feature

- 宿主可以为 Harness 接入按功能执行的取消清理，包括取消远端 A2A 任务。

### ⚡ Optimization

- 等待中的委派在轮询和执行器重启后复用同一个子任务及已准备的任务输入，不重复执行委派策略，也不计入已完成的工具调用预算。

### 🐛 Fixed

- 异步子任务不再造成生命周期记录冲突，父代理会等待子任务结果后继续。
- 取消父任务时保留子任务的真实终态，包括已经返回的结果。
- 远端取消沿用原目标配置并校验请求版本；传输失败或远端尚未确认终态时保留重试能力，避免误报取消完成。

### 升级说明

- 全部 Go modules 同步升级到 `v0.1.0-beta.7`。TypeScript 安装包作为本次 GitHub 预发布附件提供，Beta 版本不发布到 npm。
- 宿主需将 A2A 插件接入 Harness 和 HTTP 取消路由，并将 Scheduler 配置为 continuation Worker 的 `Projector`，以自动处理唤醒事件。
- 取消失败或远端仍在处理时，再次提交取消请求重试。无需迁移 HTTP v1 合同或数据库结构。

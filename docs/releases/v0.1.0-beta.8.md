## v0.1.0-beta.8 Release Notes

### ✨ Feature

- A Harness Turn can share one persistent budget across its main task and all local descendants, including Agent, Team, PlanExecute and Workflow execution. Limits cover tokens, model and tool calls, child tasks and active concurrency.
- Delegation can select a frozen role with its own instructions, model, skills, authorized tools and stricter local budget.
- Turn snapshots and feeds expose authoritative budget and subtask projections. Hosts can approve a child's exact checkpoint or cancel one subtask through the Go and TypeScript APIs.

### ⚡ Optimization

- Atomic reservations release unused capacity after settlement and suspend execution slots during budget waits and asynchronous tool polling. Replayed receipts do not charge twice.
- Subtask lifecycle facts fold into one stable task identity and remain available after reconnecting.

### 🐛 Fixed

- Planner admission waits persist and resume through continuation instead of prematurely completing an empty plan.
- Requests with unknown dispatched outcomes retain reservations across restarts; they are not automatically resent or refunded.
- Cancellation fences a queued child before it registers, preventing later execution from bypassing the cancellation.

### Upgrade notes

- Upgrade all Go modules together to `v0.1.0-beta.8` and use the matching TypeScript archive attached to this GitHub prerelease. Beta packages are not published to npm.
- Apply the Harness PostgreSQL models migration for `agent_harness_budgets`. Configure `BudgetMiddleware` at the universal model, tool and run boundaries, pass it to the Runner, and freeze `SharedBudget` and `Roles` in each new Turn configuration. Existing Turns without shared budgets retain their original accounting.
- Token limits require complete request metering and an enforceable output ceiling. Unmetered remote execution is rejected when token limits apply. Reconcile an unknown dispatched reservation with an authoritative receipt through `Settle`; cancellation alone does not refund it.

## v0.1.0-beta.8 中文版本

### ✨ Feature

- 一次 Harness Turn 可让主任务及全部本地后代共享持久化预算，覆盖 Agent、Team、PlanExecute 和 Workflow。支持限制 Token、模型与工具调用、子任务总数和实际运行并发。
- 委派可选择冻结角色，携带角色指令、模型、技能、有效工具权限和更严格的局部预算。
- Turn 快照与 Feed 提供权威预算和子任务投影；Go 与 TypeScript API 支持审批子任务的指定检查点和取消单个子任务。

### ⚡ Optimization

- 原子预留在结算后释放差额；预算等待与异步工具轮询释放执行槽位，重复回执不会重复扣减。
- 子任务生命周期按稳定身份合并，断线恢复后仍可读取同一任务。

### 🐛 Fixed

- 规划调用等待预算时持久化等待状态并通过 continuation 恢复，避免空计划提前完成。
- 请求已发出但结果未知时，跨重启保留预留，不自动重发或退款。
- 排队子任务在注册前被取消时保留取消标记，阻止恢复后继续执行。

### 升级说明

- 全部 Go modules 同步升级到 `v0.1.0-beta.8`，TypeScript 使用本次 GitHub 预发布的安装包附件。Beta 版本不发布到 npm。
- 执行 Harness PostgreSQL models 迁移以创建 `agent_harness_budgets`；在统一模型、工具和 Run 边界接入 `BudgetMiddleware`，传给 Runner，并在新 Turn 配置中冻结 `SharedBudget` 和 `Roles`。既有 Turn 沿用原计量口径。
- Token 限额要求完整请求计量与可执行的输出上限；有 Token 限额时拒绝不可计量的远端执行。未知回执的预留须凭权威回执调用 `Settle` 核对，取消本身不会退款。

# Agent Runtime 0.1.0-beta.21

This release corrects the HTTP layering of beta.20's external Tool wait
projection. The shared HTTP core again owns only feature-neutral lifecycle and
transport facts. Agent wait interpretation lives in the Agent HTTP adapter and
uses the Agent's typed public view. No host parsing of private Run state is
required.

For the shared Run endpoint, explicitly compose the optional projector:

```go
runtimehttp.NewHandler(runtimehttp.Dependencies{
    Runtime: runtime,
    Shared: shared,
    PendingToolProjector: agenthttp.PendingTool,
})
```

The core invokes the projector after object authorization. A denied request
never invokes it. The Agent start endpoint includes waiting facts through its
own adapter. Without a projector the shared Run endpoint and core
`SnapshotResponse` utility retain generic lifecycle projection and omit optional
wait metadata.

Go's `RunSnapshotResponse.PendingTool` now uses the transport-owned
`runtimehttp.PendingToolResponse`, replacing the direct pointer to
`agent.PendingToolView` introduced in beta.20. Its JSON fields, existing reviewed
wire snapshots and TypeScript types are unchanged. Existing constructor
signatures and host port requirements are unchanged; the new dependency field
is optional. Clean consumers compile the explicit projector, and a new SDK core
import test prevents concrete feature dependencies from returning unnoticed.

All P1 external-result/child-terminal waits, signal deduplication, durable wait
generations, deadline/cancel boundaries and parent/child recovery remain as in
beta.20. There is no persisted-state change or SQL migration from beta.20. Hosts
already storing typed waits can upgrade forward to this cohort. The original
beta.20 tags stay immutable; older cohorts predating typed waits must not resume
that state.

Upgrade all nine Go modules and the TypeScript client together to
`v0.1.0-beta.21`. The GitHub prerelease archive is
`orz-i-agent-runtime-client-0.1.0-beta.21.tgz`; Beta npm publication remains
disabled. Adopt this corrected release for P1. Browser environment enablement,
production session/claim/receipt APIs, server sandboxes and server execution
fallback remain outside this release.

## v0.1.0-beta.5 Release Notes

### ✨ Feature

- None.

### ⚡ Optimization

- The clean-consumer release gate now compiles every TypeScript example shipped in the package README, so stale public examples fail before publication.
- Upgrade note: runtime APIs, HTTP v1 contracts, and persisted schemas are unchanged; update all Go modules and the TypeScript archive together.

### 🐛 Fixed

- The TypeScript guide now uses the supported `agent.start`, `runs.feed`, and `snapshot.run.id` APIs instead of retired generic run and event-stream examples.

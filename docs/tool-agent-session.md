# Deprecated Tool Agent Session

`harness.OpenToolAgentSession` and `ToolAgentSessionOptions` are deprecated.
Use the [Agent Session quickstart and migration guide](agent-session.md).
The legacy constructor still automatically grants its scoped archive reader,
opts Host-certified read Tools into bounded exploration, and accepts an
unspecified output cap. Keep the original composition for in-flight legacy
Turns; the migration guide describes the equivalent settings for **new** Turns
and the next breaking removal.

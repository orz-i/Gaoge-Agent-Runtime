# Legacy text Session fixture

This retained fixture verifies `OpenTextAgentSession` compatibility, including
the distinction between replaying the original admission and loading a prior
Turn after Host history advances. It is not a second onboarding path.

Start with the [Agent Session quickstart](../../../../docs/agent-session.md)
for both bounded text and local-Tool Sessions. For a text-only session, omit
`LocalTools`. See the same guide for migration and planned removal of the
legacy facade and this example.
